# Project-SI

Regroupement des travaux pratiques du cours « Systèmes d’information ».

## Contenu

- `tp1/` — POO, SOLID, Design Patterns
- `tp2/` — Base de données, Docker, PostgreSQL
- `tp3/` — Architecture applicative (client/serveur, HTTP, TCP)

## Organisation

Chaque dossier contient son propre `README.md` avec les consignes d’exécution, la structure interne et les commandes utiles.

## Démarrage rapide

1. Choisir le TP à exécuter (`tp1`, `tp2` ou `tp3`).
2. Se rendre dans le dossier concerné.
3. Suivre le `README.md` du TP.

## Notes

Les projets sont conservés tels que fournis par les supports pédagogiques, avec les correctifs nécessaires apportés au niveau des scripts d’exécution.
